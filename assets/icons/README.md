# assets/icons

Los iconos de la interfaz son SVG en línea dentro de `index.html` (para que no haya
peticiones externas ni parpadeos). Aquí se guarda el favicon y puedes añadir los
iconos propios que quieras usar, por ejemplo para una PWA:

- `favicon.svg` — icono de la pestaña del navegador (velas japonesas).
